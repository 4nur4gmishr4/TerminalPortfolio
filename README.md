## ⚡ Tech Stack

This portfolio is built for speed and visual excellence using:
- **Core:** React 18 & TypeScript
- **Styling:** Highly optimized pure CSS (with variables and responsive tokens)
- **Animations:** Framer Motion & Lottie for buttery-smooth micro-interactions
- **Build Tool:** Vite (for lightning-fast HMR and optimized production bundling)
- **Routing:** React Router v6

## 🛠️ Running Locally

If you'd like to explore the codebase or run it on your own machine:

```bash
# 1. Clone the repository
git clone https://github.com/4nur4gmishr4/TerminalPortfolio.git

# 2. Navigate into the directory
cd TerminalPortfolio

# 3. Install dependencies
npm install

# 4. Start the development server
npm run dev
```
